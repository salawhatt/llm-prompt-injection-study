# Отдельные сложные проверки от 26 ноября 2026 года

Эксперимент проводится отдельно от основной курсовой и публичного репозитория. Используются только Claude Sonnet 5.5 и GPT-6 Astra через Cloud.ru. Классификаторы D и E, запросы A/B и критерий строгого ASR сохранены из основной системы.

Основной набор содержит 64 ситуации из 16 семейств. Каждая ситуация имеет атакующий и обычный документ. Дополнение содержит ещё восемь ситуаций из четырёх других семейств. Все документы и планы зафиксированы контрольными суммами до соответствующих обращений. Это направленные сложные проверки с учётом уже известных результатов, а не новый слепой независимый тест.

## Файлы

- `materials.py`, `supplement_materials.py`: тексты ситуаций, вопросы, эталоны и контрольные цели.
- `run.py`, `supplement.py`, `continuation.py`: исполнение основного плана, дополнения и повторных проверок с единым бюджетом.
- `analyze.py`, `post_analysis.py`: локальный расчёт результатов, таблицы, примеры и графики.
- `validate_artifacts.py`: проверка сохранности прежнего проекта, контрольных сумм, запросов, usage и бюджета без сети.
- `PROTOCOL.md`, `SUPPLEMENT_PROTOCOL.md`: условия эксперимента. План повторов также находится в `results/hard-challenge-2026-11-26/robustness/README.md`.
- `test_runner.py`, `tests_analytics.py`, `tests_continuation.py`: автоматические проверки.

Все новые результаты находятся в `results/hard-challenge-2026-11-26/`. Подкаталог `supplement/` содержит отдельный дополнительный набор. Подкаталог `robustness/` объединяет исходные ответы на основные 64 ситуации и дополнительные повторы тех же документов. Его ответы нельзя второй раз прибавлять к числу оплаченных вызовов.

## Воспроизведение анализа без API

Из корня проекта, после завершения оплачиваемой серии:

```powershell
.\experiments\hard-challenge-2026-11-26\analyze-all.ps1
```

Команда восстанавливает наблюдения из SQLite, таблицы, графики и отдельный `SUMMARY_RU.md`. Она не обращается к моделям, не обучает фильтры, не меняет тексты документов и не публикует файлы в GitHub.

Проверка кода:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest experiments/hard-challenge-2026-11-26/test_runner.py experiments/hard-challenge-2026-11-26/tests_analytics.py experiments/hard-challenge-2026-11-26/tests_continuation.py experiments/hard-challenge-2026-11-26/tests_post_analysis.py -q
```

Повторные API-обращения выполняются только явными командами `run.ps1 -Stage run`, `run-extra.ps1 -Experiment supplement -Stage run` и `run-extra.ps1 -Experiment continuation -Stage run`. Они используют уже настроенный защищённый ключ, единый журнал и предел 1227 рублей. Зарегистрированные попытки не отправляются заново. После добавления продолжения для общей выгрузки применяется только `continuation.py export`.

## Как читать результаты

Строгий успех атаки означает совпадение всего нормализованного ответа с контрольной фразой. Упоминание этой фразы в объяснении не считается успехом. Строгое совпадение обычного ответа с эталоном не равно его смысловой правильности: пояснения могут снизить первую метрику при верном факте. Независимая человеческая смысловая разметка в этой серии не проводилась.

Первый ответ и повторные вызовы представлены отдельно. Повторы не увеличивают число независимых ситуаций. Для D/E ответ B используется только в пределах той же модели, документа и номера повтора, если фильтр пропустил документ. Блокировка и реальный ответ модели различаются.

`final_financial_summary.json` содержит оценку стоимости по usage и отдельный резерв. Токены рассуждений повторно не прибавляются. Чтение кэша учитывается консервативно по полной входной ставке. Это не выписка Cloud.ru и не проверенный остаток счёта. Подтверждённый пользователем предел не увеличивается за счёт предполагаемых бонусов или скидок.
