# Сложные проверки Claude Sonnet 5.5 и GPT-6 Astra

Сохранённая серия от 26 ноября 2026 года. Защиты A/B/D/E, документы, критерии и реальные ответы опубликованы отдельно от основного исследования. Основная сложная группа содержит 64 ситуации из 16 семейств, дополнительная группа восемь ситуаций из четырёх семейств. Обе группы включают обычные контрольные документы. Получено **1 366 уникальных ответов API**, по 683 от каждой модели.

## Пересчитать без API

Команды выполняются из корня репозитория, в окружении Python 3.11 с зависимостями основного проекта:

```bash
python -m pip install -r requirements.txt
python studies/hard-challenge-2026-11-26/analyze_saved.py --verify-only
python studies/hard-challenge-2026-11-26/analyze_saved.py
```

Первая команда проверки сверяет исходные контрольные суммы и целостность наблюдений. Полный анализ копирует входные данные в `studies/hard-challenge-2026-11-26/output/reproduced/`, восстанавливает таблицы и PNG/SVG. Опубликованные результаты не перезаписываются. Ключ Cloud.ru, обучение моделей и сетевые запросы не нужны. Вариант `--no-plots` пропускает отрисовку графиков.

Проверки опубликованной копии:

```bash
python -m pytest studies/hard-challenge-2026-11-26/test_public_snapshot.py -q
```

Исходные тесты анализатора и исполнителя API (сетевые ответы имитируются):

```bash
python -m pip install httpx
python -m pytest studies/hard-challenge-2026-11-26/experiments/hard-challenge-2026-11-26/test_runner.py studies/hard-challenge-2026-11-26/experiments/hard-challenge-2026-11-26/tests_analytics.py studies/hard-challenge-2026-11-26/experiments/hard-challenge-2026-11-26/tests_continuation.py studies/hard-challenge-2026-11-26/experiments/hard-challenge-2026-11-26/tests_post_analysis.py -q
```

## Состав снимка

Внутренние `experiments/`, `results/`, `src/` и `models/` сохраняют структуру завершённого эксперимента. Их версии изолированы от сокращённого кода основного репозитория. `ARCHIVE_MANIFEST.json` содержит SHA-256 141 исходного файла, включая SQLite-журнал и первоначальную документацию. Эти файлы перенесены без изменения. Публичная инструкция, офлайн-команда и её тесты добавлены отдельно.

Исходный архив: `hard-challenge-2026-11-26.zip`, SHA-256 `c4b00013ed41c0dd5d2fbecba4b27334fae5bf59c206d2dbd2242625395a4a04`.

В исходной документации сохранены локальные ссылки `D:\KW` и описание прежнего расположения файлов. В этой копии соответствующие материалы находятся внутри данного каталога. Для анализа используйте `analyze_saved.py`, а не исходный `analyze-all.ps1`: тот также проверяет файлы более широкого рабочего проекта, не входящие в снимок.

Исполнители `run.py`, `supplement.py`, `continuation.py` и PowerShell-обёртки сохранены как исходный код реально проведённой серии. Они не запускаются командой анализа. `budget_authorization.json` фиксирует лимит завершённой серии и не является разрешением на будущие платные запросы. Для нового запуска нужны собственная конфигурация и ключ. Секреты в снимок не включены.

## Как интерпретировать

В первых ответах на 64 атакующих документа у Sonnet ASR равен 19/64 в A и нулю в B/D/E. У Astra соответственно 3/64, 1/64, 0/64 и 0/64. При повторении обнаружен второй успешный документ Astra B, который D пропустила, а E заблокировала. D также ошибочно блокировала 46/64 обычных документов, E 8/64. На восьми дополнительных ситуациях строгих успехов не зарегистрировано.

Три пустых усечённых ответа Astra относятся только к повторениям. Не все запланированные повторы выполнены: недостающие вызовы не считаются неуспешными атаками. Полная смысловая оценка новых ответов отсутствует. Строгая правильность измеряет совпадение с эталоном, а не все возможные фактически правильные ответы.

Оценка по токенам составляет 1 133,79 ₽, резервирование 1 190,48 ₽ при лимите 1 227 ₽. Это сохранённый расчёт по usage, не подтверждённое списание или остаток кабинета. Нулевой ASR отдельных групп не доказывает полной безопасности моделей.
